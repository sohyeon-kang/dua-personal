# DUA 모바일 · 지하철 여행

사용자가 제공한 `wireframe.png`의 네 화면을 구현했습니다. `/mobile/`의 디자인을 교체했으며 기존 `/page1/`, `/page2/`, `/page3/`는 유지합니다.

- 여행 조건: 지하철 일러스트, 지역·동행·날씨를 잇는 노선형 선택, 오전·오후 시간대 메모 선택.
- 추천 코스: A/B/C 역 형태의 탭, 지도, 방문 순서, 북마크.
- 이동 안내: 지하철 / 방문 일정 탭, 부산역 출발 안내, 실제 장소 정보와 길찾기.
- 저장: 여러 코스와 개별 장소 보관, 선택 순서대로 구간별 도보 길찾기 생성.

주요 색상은 청록 `#03695e`, 연두 `#6daf5f`, 하늘색 `#239dca`, 연한 파랑 `#a5c6db`, 배경 패널 `#e7e9d8`입니다.

## 실행

프로젝트 루트에서 `npm run dev` 실행 후 `http://localhost:8080/mobile/`을 엽니다. 기존 추천 API를 그대로 사용합니다.

검색·선택 상태는 `sessionStorage`의 `dua.mobile.*`, 저장 코스·장소는 `localStorage`의 `dua.mobile.bookmarks.v1`에 보관합니다. 북마크는 현재 브라우저에만 저장되며 브라우저 데이터 삭제 시 함께 사라집니다.

## 현재 연결 범위

- 시간대는 여행 메모로 보관하며 추천 알고리즘에는 아직 반영하지 않습니다.
- 탑승 방향·빠른 환승·하차역·출구·열차 운행은 데이터 연결 전이므로 `확인 예정`으로 표시합니다.
- 영업시간, 노을 시간, 행사 일정은 미연결 상태입니다.
- 지도 선과 거리는 직선 기준이며 실제 도보 시간이나 최단 경로가 아닙니다. 저장 장소 경로는 사용자가 선택한 순서대로 각 구간의 카카오맵 링크를 제공합니다.
- 지도 SDK를 사용할 수 없으면 대체 안내와 외부 카카오맵 링크를 표시합니다.

## 검증

기존 `npm test` 9개 통과. 모바일 화면은 320 / 390 / 768px에서 확인하며, 검색 → 코스 선택 → 저장, 장소 저장 및 구간별 경로 생성 흐름을 브라우저로 검증합니다.
